# GS-OPD LIBERO-Safety L0/L1/L2 任务采集清单（本地配置盘点）

**日期：2026-10-25；范围：`obstacle_avoidance` 与 `obstacle_avoidance_human`，共 30 个任务。** 本表来自本地 BDDL、benchmark task map 和对应 `.pruned_init` 文件；未读取/下载官方示范数据，未运行 MuJoCo 或 π₀.₅ Rollout。

## 路线与接触解释

严格保留：原始 π₀.₅ Student Rollout → 暴力搜索任务成功轨迹（允许不安全）→ 利用 GS-OPD 自身历史成功经验做几何重定位与安全重构 → MuJoCo 完整验证 → 生成 GS-OPD 安全训练 Episode。LIBERO-Safety 官方安全示范的动作、关键帧、轨迹和专家标签不参与搜索先验、冷启动、重定位或当前 Episode；只作为未来独立 Offline SFT Baseline。

BDDL `:goal` 是原生任务成功条件。`:constraints` 中的 `CheckRobotContact` / `CheckContact` 在本地谓词实现中返回接触布尔值并形成逐步 contact cost，因此下面把对象列为显式禁止接触候选；这不等同于成功谓词、hard-stop 规则或完整安全证明。列出的目标抓取、On/In 支撑/容纳以及关门所需接触是操作语义推断，不是 BDDL 完整 allowlist；其他接触保持 `unknown`。

每个 `.pruned_init` 张量有 50 个候选行。表中“初始状态”列按 BDDL 原生符号关系展开；本轮未创建环境将张量解码成物理世界坐标。L1/L2 不保证比低级别单调更难，必须依据每个任务实际 `:dynamics` 和操作技能判断。
